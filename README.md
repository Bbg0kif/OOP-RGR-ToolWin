# Розрахунково-графічна робота з ООП — ToolWin

Варіант 1.

Реалізовано модуль немодального діалогового вікна ToolWin
і дві програми, які його використовують.

## Вимоги для збирання

- Windows.
- Visual Studio Community з компонентами розробки класичних
  програм мовою C++ та Windows SDK.
- Для основного проєкту використовується набір інструментів v145.

## Запуск

1. Відкрити рішення ToolWinDemo.slnx у Visual Studio.
2. Вибрати конфігурацію Debug та платформу x64.
3. У Solution Explorer натиснути правою кнопкою на потрібному
   проєкті та вибрати Set as Startup Project.
4. Запустити програму через F5.
5. Відкрити панель через Tools → Show ToolWin.

Проєкти:

- ToolWinDemo — демонстраційний графічний редактор.
- ToolWinReuse — лічильник для перевірки повторного використання модуля.

## Структура програми

- ToolWin.h, ToolWin.cpp — модуль вікна інструментів.
- main.cpp — головне вікно редактора, меню та клас DemoToolWin.
- DrawingCanvas.h, DrawingCanvas.cpp — зберігання і малювання фігур.
- ToolImages.h, ToolImages.cpp — створення зображень кнопок.
- ToolWinReuse/main.cpp — окрема програма-лічильник.

## Модуль ToolWin

Інтерфейс модуля — клас MyToolWinClass.

Основні методи:

- Create(instance, owner, nx, ny, buttonSize) — створення вікна
  із заданою кількістю стовпців, рядків і розміром квадратних кнопок.
- SetHints(hints) — передавання текстових підказок.
- SetImages(images) — передавання дескрипторів зображень кнопок.
- SetModeButtons(indices) — визначення кнопок вибору режиму.
- Show() — показ створеного вікна.
- Close() — закриття вікна.
- GetHandle() — отримання дескриптора вікна.

Реакція на натискання задається в класі-нащадку через
перевизначення віртуального методу OnToolClick(buttonIndex).

Індекси кнопок у програмному інтерфейсі починаються з нуля.

Зображення та кнопки режимів налаштовуються до створення вікна.
Якщо передано непорожній список зображень або підказок,
кількість його елементів має дорівнювати nx × ny.

Модуль копіює тексти підказок, але не володіє переданими
об’єктами HBITMAP. Програма, яка створила зображення,
повинна зберігати їх протягом використання кнопками
та звільнити після закриття вікна.

Немодальний діалог створюється за шаблоном у пам’яті,
тому окремий ресурс діалогу в .rc не потрібний.

Модуль використовує Windows API та Comctl32.lib.
Підключення бібліотеки задане в ToolWin.cpp.
У циклі повідомлень програми викликається IsDialogMessageW.

## Графічний редактор

Призначення кнопок у порядку зліва направо, рядок за рядком:

1. Точка.
2. Лінія.
3. Прямокутник.
4. Еліпс.
5. Чорний колір.
6. Червоний колір.
7. Зелений колір.
8. Синій колір.
9. Тонка лінія.
10. Товста лінія.
11. Перемикання заливки.
12. Видалення останньої фігури.
13. Очищення малюнка.
14. Довідка.

Для малювання потрібно вибрати інструмент і натиснути
ліву кнопку миші в головному вікні. Для лінії, прямокутника
та еліпса потрібно перетягнути курсор, утримуючи кнопку.

Esc під час малювання скасовує незавершену фігуру.

Колір, товщина та заливка застосовуються до нових фігур.
Заливка впливає на прямокутники та еліпси.

Через меню Tools можна вибрати:

- конфігурацію 2 × 7, 1 × 14 або 14 × 1;
- розмір кнопок 32, 40 або 48 пікселів.

Закриття ToolWin не видаляє малюнок і не скидає вибраний
інструмент. Фігури зберігаються в пам’яті до завершення
роботи програми; збереження малюнка у файл не реалізоване.

## Повторне використання

Проєкт ToolWinReuse підключає ті самі ToolWin.h та ToolWin.cpp
без зміни їхнього коду.

Він створює сітку 2 × 3 із кнопками розміром 60 × 60 пікселів.
Зображення не передаються, тому кнопки мають текстові номери.

Дії кнопок:

1. Додати 1.
2. Відняти 1.
3. Додати 10.
4. Відняти 10.
5. Обнулити лічильник.
6. Показати довідку.

Значення лічильника відображається в заголовку головного вікна.

Приклад демонструє зміну кількості кнопок, розмірів,
підказок і дій через інтерфейс модуля та клас-нащадок.
